# Privacy and redistribution controls

This staging package is author-private. It is not approved for public release, blinded review, journal submission, or data redistribution.

The final private package may include detailed derived evidence needed for reproduction, subject to source terms. It must not include credentials, caches, unrelated projects, unneeded local paths, or active/incomplete run files.

A public or blinded package requires separate authorization and an explicit allowlist. Remove author approval identity metadata, private criticism and correspondence, local usernames and paths, restricted source records, and any material whose redistribution rights have not been established. Record every exclusion and replacement in `PUBLIC_PACKAGE_EXCLUSIONS.csv`. A derived dataset is not automatically redistributable.
